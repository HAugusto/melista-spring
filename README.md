# 🛒✨ melista-spring

Sistema para o usuário criar listas de produtos do mercado, organizar compras e analisar o custeio total de forma prática.

## 🎯👀 Visão geral

O projeto `melista-spring` nasceu para resolver uma necessidade simples e muito útil no dia a dia: ajudar a pessoa a montar uma lista de compras, comparar os preços entre diferentes redes de mercado e entender melhor o custo final da compra.

A ideia central é permitir que o usuário:

- 📝 crie listas de produtos;
- 🛍️ associe itens às redes cadastradas;
- 💰 compare preços entre fornecedores;
- 📊 visualize o impacto financeiro da escolha;
- 🧠 tome decisões de compra com base em análise de custeio.

Em outras palavras, este projeto é uma base para uma solução de apoio à compra inteligente no varejo.

## 🧩🎯 Objetivo do produto

O objetivo principal é oferecer uma plataforma que ajude o usuário a:

- montar listas de compras de forma organizada;
- escolher a rede mais econômica para cada compra;
- entender o custo total da lista;
- facilitar a comparação entre preços e ofertas;
- reduzir desperdícios e melhorar o controle financeiro doméstico.

## 🛠️📦 Funcionalidades planejadas

- 👤 cadastro de usuários;
- 🛍️ criação e gerenciamento de listas de compras;
- 🧾 cadastro de produtos;
- 🏪 cadastro de redes de mercado;
- 💸 comparação de preços por produto e rede;
- 📉 cálculo do custo total da lista;
- 🧮 análise de custeio por item, quantidade e valor final;
- 📊 relatórios simples de comparação econômica.
